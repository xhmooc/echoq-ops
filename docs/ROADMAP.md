# 后续路线图

这份文档记录「接下来靠什么继续变好」。每次做新东西前先在这里认领，做完回填状态和版本。
当前两条主线：**手绘插画（学 anidoodle）**、**公众号排版（学 huasheng_editor）**。

---

## 一、手绘插画：继续向 anidoodle 学（长期主线）

来源：`https://github.com/alexgreensh/anidoodle`。核心不是素材库，而是「一种风格 = 一种做标记的方式」：笔尖锥度、压感、抖动、渗色、颗粒、纸张、套印偏移，以及真实的落笔顺序。

当前实现：`desktop/src/render/sketch.ts`，风格 = 绘制原语 + 构图规则 + 种子。

### 已落地
- [x] 5 种媒材：平涂向量、铅笔淡彩、马克漫画、水墨国风、剪纸节日
- [x] 随机只来自 `mulberry32(seed)`，同草稿同构图逐像素一致
- [x] 「换一张构图」= 换种子重渲
- [x] 3:4 竖版（封面 / 内容 / 尾页）与公众号 2.35:1 宽幅
- [x] 出图前跑版式体检，文字块不裁切

### P0 · 质量走查（每新增一种媒材必做）
- [ ] 2x 放大检查最难的局部：笔尖起收、颗粒断裂、颜料积边、套印偏移
- [ ] 同 seed 同图的回归测试（现有冒烟，扩充到每种媒材）
- [ ] 反廉价感清单：椭圆拼主体、只换色不换笔、每帧不一致
- [ ] 每种媒材给 3 张「最差输入」样本（超长标题、纯英文、无关键词），确认不塌

### P1 · 媒材扩充
- [ ] 孔版印刷 riso：两色套印偏移 + 半调网点 + 纸张吸墨毛边
- [ ] 木刻版画：刀口有方向，阳刻线条粗、阴刻面留白
- [ ] 蜡笔 + 彩铅：蜡质结块、纸齿漏白，叠色有方向感
- [ ] 每种媒材必须有独立「做标记」参数，不能只换配色（硬门槛）

### P1 · 主体与构图
- [ ] 主体库从 10 个扩到 24 个：人物动作、场景、抽象符号
- [ ] 双主体关系：对话、对比、因果、递进
- [ ] 公众号宽幅 / 竖版 / 正文横图三套构图模板，标题与主体的避让规则固定
- [ ] 手写标题：笔画粗细与媒材一致

### P2 · 产品化
- [ ] 风格包绑定账号/品牌：同一账号长期只用一种「手」
- [ ] 插画历史与复用：同 draft 多版本可回看、可锁定
- [ ] 正文插图按小节语义自动配图
- [ ] 封面 + 正文图成套生成，构图色彩互相呼应
- [ ] 明确不做：整仓接入 anidoodle、运行时读时钟、用 `ctx.filter` 做质感

### 工程约束（沿用）
- 纯函数 + seeded rng，不读时钟；纹理最后叠；交付前 2x 走查
- 只走本机 HTML→PNG 管线，不接付费出图；确定性优先于随机惊喜

## 二、公众号排版：学 huasheng_editor

来源：`https://github.com/alchaincyf/huasheng_editor`（MIT）与线上 `https://editor.huasheng.ai/`。它的价值是：主题成套、每个标签内联样式、容器宽度/字体/行高成套、渐变与阴影、图片最大高度、表格与代码块可读性、多图网格；编辑侧是 Markdown 源码 + 实时预览，排版只作用于预览与发布，不改写正文。

当前实现：主题数据在 `desktop/src/data/themes.ts`，渲染与套用在 `desktop/src/services/richtext.ts`。

- [x] 主题清单 API：`GET /api/richtext/themes`（按分组返回）
- [x] 内容与样式分离：草稿只存 `wx_theme`，预览与发布时套主题
- [x] Markdown 编辑：正文「文本 / MD」切换，右侧手机预览实时排版（`/api/richtext/render`）
- [x] 标题内联覆盖：标题里的 strong/em/a/code 统一 `color:inherit`
- [x] 多图网格：连续 2/3 张并排，4 张 2×2，5 张以上三列（Grid → Table 兼容公众号）
- [x] 首块 `margin-top:0`
- [x] 正文外链自动转「文字[n]」+ 文末参考链接
- [ ] 图片说明与图注：`figcaption` 统一风格
- [ ] 标记语法：引用卡、提示卡、目录、步骤条、金句块
- [ ] 代码高亮产物直接内联（不依赖外部样式表）
- [ ] 复制到公众号前做「样式收敛」检查：不支持的 CSS 降级而不是整段丢失
- [ ] 排版预设与账号绑定，减少每次手选

## 三、内容与平台模型

- [x] 一个内容一个草稿：平台切换在原草稿上完成，不再复制新草稿
- [x] 跨平台保留全部图片：公众号取第 1 张作封面，其余可一键插入正文
- [x] 平台能力矩阵集中在 `desktop/src/core/platform.ts`
- [ ] 同一草稿的多平台版本视图（小红书文案 / 公众号长文两个视图，正文互转）
- [ ] 已发布内容的 6 小时自动回读（当前只有手动同步）
- [ ] 平台侧下架 / 违规巡检（当前 health-check 为简化版）

## 四、维护约定

- 新增风格 / 主题 / 平台能力，先改本文档再写代码；完成后勾掉并补一句结果
- 交付前至少跑 `cd desktop && npm run build`，并手动冒烟相关链路
- 不引入付费出图；不把样式写死在前端，主题与风格清单统一由后端返回
- 旧版 Python 运营台已移除，不再作为对拍基线；历史实现只作参考
