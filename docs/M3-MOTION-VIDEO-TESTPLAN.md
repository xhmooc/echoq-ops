# M3 动效与图文转视频 · 验证方案

> 版本：v1.0 · 2026-11-25
> 配套设计：docs/M3-MOTION-VIDEO-DESIGN.md
> 约定：验证用临时冒烟脚本置于 desktop/ 下，全绿后随版本提交或按惯例删除（M3 编辑器先例：E2E 通过后清理）。

---

## 1. 验证分层

| 层 | 手段 | 覆盖 |
| --- | --- | --- |
| L1 纯函数 | Node 直调（tsx/node） | 时间轴计算、参数校验、画幅档案、字幕分句均分 |
| L2 渲染服务 | 临时脚本直调 renderMotion/renderSlideshow（ELECTRON_RUN_AS_NODE 不可用，需 Electron 主进程入口，沿用 smoke-custom 先例） | HTML 生成、逐帧渲染、ffmpeg 合成、落盘、回退 |
| L3 API | 起 server + HTTP 断言（沿用 smoke-m3-api 模式） | 扩参校验、缺省兼容、产物 URL 可取回 |
| L4 前端 E2E | Edge headless CDP（沿用 smoke-m3-e2e 模式） | 动效设置行、按钮链路、媒体区角标 |
| L5 人工走查 | 真机安装包 | 观感、循环流畅度、音画同步 |

## 2. 确定性与循环质量（核心断言）

1. **同参同像素**：同（草稿，template，duration，canvas，seed）渲染两遍，逐帧 PNG md5 序列完全一致（延续手绘「同 seed 同图」标准）。
2. **循环无跳变**：首帧与末帧像素差（逐通道均值差）低于阈值（≤2/255）；`fade-seq` 类范式末帧须等于「全部元素已入场」的定格帧。
3. **`__seek` 纯函数性**：以乱序 t 序列 [3.2, 0.4, 5.8, 0.4] 求值，相同 t 的帧 md5 一致（防内部读时钟/累积状态）。

## 3. 多画幅与体检

| 画幅 | 断言 |
| --- | --- |
| portrait 1080×1440 | 现状回归：产物尺寸不变、老 API 零参调用结果与 0.2.9 一致 |
| square 1080×1080 | 首末帧 checkBlocks 无 errors；标题不越安全边距 |
| wide 1080×460 | 标题单行不裁切；底部进度条位于画布内 |
| landscape 1920×1080 | 同上；文字区不进左右 5% 边缘带 |

体检失败样例：构造超长标题（>40 字）+ wide 画幅 → 断言 errors 拦截、不落盘、返回原因。

## 4. 范式库断言（每范式至少 2 条）

| 范式 | 断言 |
| --- | --- |
| fade-seq | 参数化后旧行为回归（缺省参数产物与现版本逐帧一致） |
| type-in | 字符 stagger：t=0.5s 与 t=2s 帧的已显字符数单调不减；末帧全显 |
| kenburns | 缩放单调（首帧 scale=1.0 < 末帧 ≤1.08）；底图不露白边 |
| sketch-grow | 同 seed 逐帧一致（沿用种子机制）；笔画显现进度单调 |
| pop-sticker | spring 入场无越出画布；末帧定格 |

## 5. 图组转视频与配乐

- 10 张图 + 默认字幕 → slideshow.mp4：时长 = 10×2.5s ±0.5s（ffprobe 校验）、分辨率 1080×1920、帧数 = duration×fps ±2；
- 字幕条带不进抖音底部 520px 禁区（末帧探针）；
- 混音：带 bgm 合成后音轨存在（ffprobe audio stream）、响度 ≈ -14 LUFS（±2）；`bgm:"none"` 无音轨；
- 图片缺失（配图为空）→ 400 + 明确原因，不生成半成品。

## 6. 性能与体积预算

| 指标 | 预算 | 说明 |
| --- | --- | --- |
| 6s 动效（151 帧）总耗时 | ≤90s | 以 0.2.9 实测为基线校准 |
| GIF 体积 | <5MB | 超标自动降 12fps 重试一次 |
| 动效 MP4（810×1080） | ≤8MB | |
| 图组视频（10 张，626 帧） | 逐帧渲染实测校准；合成（ffmpeg）阶段 ≤30s | UPGRADE-PLAN 原「≤30s」按合成阶段理解；逐帧阶段在 M3-a 完成后先实测再定档，必要时启用 fps=15 降档 |
| slideshow.mp4（25s 1080×1920） | ≤25MB | crf18 基线 |

## 7. 失败回退与健壮性

| 场景 | 期望 |
| --- | --- |
| PATH 与内置目录均无 ffmpeg | motion/slideshow 返回明确 note「未检测到 ffmpeg」；静态配图不受影响；不崩溃 |
| 单帧渲染超时 | 中止并回退静态首帧 + note（现状机制回归） |
| 非法参数（template=foo / duration=5 / canvas=9:16） | 400 + 中文原因；缺省参数行为不变 |
| 并发生成（连点两次按钮） | 串行队列化，第二个请求等待而非报错 |

## 9. 人工走查清单（L5）

- [ ] 三种画幅动效在手机预览与素材区观感正常，无文字裁切
- [ ] 循环播放首尾衔接无跳变感
- [ ] 图组视频字幕与图片切换对齐，配乐音量不抢字幕（若有人声场景再评估）
- [ ] 无 ffmpeg 环境的干净机器（或临时移除 PATH 模拟）提示明确、静态功能完好
- [ ] 安装版实机：动效生成期间 UI 不卡顿、可继续编辑文案
