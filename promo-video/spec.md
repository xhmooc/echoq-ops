# Design Spec · 应声运营宣传视频（Launch Film）

## 项目是什么
为 EchoQ Ops（应声运营）做一支品牌 launch film，用于官网、公众号、B 站/小红书账号传播。它要建立「把内容运营做成一条流水线」的产品认知，并以「把时间，留给重要的事」收束情感。

## 受众与场景
- 主受众：小红书个人创作者与小型运营团队（1-5 人），每天在 6+ 个工具之间切换：找选题、写稿、做图、预览、发布、看数据
- 次受众：代运营机构，管多个账号矩阵
- 外受众：对「AI 运营工具」持观望态度的普通博主（担心数据安全、担心像机器人）
- 观看场景：手机信息流里点开（公众号/B站/小红书），前 5 秒决定去留

## 核心信息（分点）
1. 痛点：内容运营的活散落在六个工具里，复制粘贴、来回切窗口
2. 方案：EchoQ Ops 一个窗口，一条链路跑完——选题 → 成稿 → 配图 → 预览 → 发布回收
3. 信任：本地优先，数据不出本机，Cookie 本地加密
4. 规模感：多账号队列，各排各的，自动重试
5. 情感收束：把时间，留给重要的事

## 情感基调
克制、有产品力、高级。不吵闹、不堆功能词；像产品发布会片段，不像促销广告。

## 输出格式与尺寸（三方向统一）
- 画布：1920×1080，横片
- 时长：约 30 秒
- 交付：MP4（60fps，含 BGM+SFX）＋ 30fps 预览版 ＋ 首帧海报
- 假设（assumption，用户未明确指定，按行业惯例补齐）：时长 30s；横版 16:9；中文配音暂不做，用字幕卡叙事；BGM+SFX 双轨

## 已知约束
- 品牌色必须用 #ff2442 / #ff7a96 体系（用户明确要求官网与品牌物料用小红书红粉配色）
- 标语必须出现「把时间，留给重要的事」
- 产品名只用「应声运营 / EchoQ Ops」
- 不虚构数据：界面数字用官网 mock 同款（今日已发 12 篇、曝光 3.8 万、队列 09:40）

## 图片需求
- App 图标：icon.png（已有，真实资产）
- 产品界面：按官网 mock 以 HTML 重建（选题池/草稿箱/发布队列三栏看板），不用截图截屏
- 无需外景实拍；三方向均以程序化视觉 + 重建 UI 为主角素材
