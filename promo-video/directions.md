# Directions · 应声运营宣传视频 六候选

> 秒数轮盘：S=31 → web 区 31%20+1=12 号「暖色出版物 Warm Editorial」；east 区 31%12+1=8 号「杉浦康平信息曼荼罗」。外观账本为空，无历史撞车。

## 六张方向卡

### A · 最佳设计师｜Apple 工业设计团队
- 借的机制：产品影片里「单一 hero 物体 + 组件精确编舞」——一个连续推轨镜头串起所有部件，物件沿隐形轨道滑入位，节奏与呼吸感来自缓动曲线而非快切
- 不借的：Apple 的银灰金属质感与英文霓虹字；颜色从品牌小红书红粉长，界面用中文重建
- 主角素材：HTML 重建的 EchoQ Ops 桌面窗口（真实看板数据）+ 五枚流程玻璃胶囊
- 骨架：亮色摄影棚底，窗口居右浮起，左侧大标题，底部一条流水线串五个动作
- 胆量花在哪：整支片一个镜头不切，靠推轨穿过五个站点
- form 来自内容的哪里：「流水线」是官网原话，画面就是一条看得见的传送线

### B · 最佳设计师｜原研哉（Kenya Hara）
- 借的机制：『白』的空寂——大留白做主角、信息一次只出现一件、竖排与横排并置制造呼吸
- 不借的：无印良品的米色系与性冷淡灰；红从品牌来（#ff2442 只用一处，如一方朱印）
- 主角素材：宋体大字标语 + 一条「一日时间轴」 + 静置角落的小窗口
- 骨架：暖纸底全留白，大字压中，底部一条细时间线串起发布节点与「被还回来的时间」
- 胆量花在哪：产品窗口只占画面 8%，小到近乎消失
- form 来自内容的哪里：标语「把时间，留给重要的事」——画面本身就是被腾出来的时间

### C · 现实参照｜Linear「The Linear Look」× Vercel Ship 发布片
- 借的机制：暗底发光渐变边框 + bento 分块 + 数据呼吸（数字跳动、状态灯亮起）+ 动感字卡快切
- 不借的：Linear 的蓝紫 #5E6AD2；accent 全部换成品牌红粉，发光用暖红
- 主角素材：暗色玻璃发布队列面板（真实队列数据 09:40/12:10/18:30）+ 漂浮统计胶囊
- 骨架：近黑底 + 红色辉光，左动感大字、右斜切玻璃面板，快节奏
- 胆量花在哪：把「发布队列」做成一块悬浮的发光圣物
- form 来自内容的哪里：运营者深夜看数据的心跳感

### D · 现实参照｜Stripe 斜切流体渐变（备选）
- 借的机制：斜切分区 + 多色流体渐变带压理性栅格；红粉渐变 (#ff2442→#ff7a96) 天然适配
- 主角素材：渐变 hero + 重建 UI 卡片
- 骨架：上渐变下白栅格
- form：品牌红粉的流动感 = 内容在生产线上流动

### E · 秒数轮盘｜Web #12 暖色出版物 Warm Editorial（备选）
- 抽中：Anthropic/Claude 系奶油纸底+单点缀+衬线混排（注意：这是模型默认外观家族，若选它需刻意做出差别）
- 主角素材：衬线大标题 + 红色单点缀
- form：像一本「运营工作手册」的扉页

### F · 秒数轮盘｜East #8 杉浦康平信息曼荼罗（备选）
- 抽中：同心环盘（外环节气/刻度、中环扇区、中心红点）——可做成「运营一日时钟」：24 小时刻度、发布时段为扇区、中心一枚品牌红点
- 主角素材：程序化 SVG 同心盘
- form：把「发布队列的一天」画成一张宇宙图

## 选定三张（彼此温度/运动语言/骨架均不同）
1. **A 流水线**（亮、连续运镜、产品编舞）
2. **C 数据流**（暗、快切、发光玻璃）
3. **B 时间归还**（暖、慢、留白人文）

备选：D Stripe 渐变、E Warm Editorial、F 杉浦曼荼罗——看中哪个可换入重做完整版。
